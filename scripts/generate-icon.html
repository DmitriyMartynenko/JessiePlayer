Jessie Player — Icon Generator

Рендерить JP-логотип у всіх потрібних розмірах.
Скачай PNG → заміни src/images/icon.png (256px)
Потім конвертуй 256px PNG → ICO на icoconvert.com → заміни src/images/icon.ico

Після заміни файлів:
1. Зупини застосунок
2. Заміни src/images/icon.png файлом 256×256 завантаженим вище
3. Відкрий icoconvert.com → завантаж 256px PNG → Export as ICO (обери всі розміри: 16, 32, 48, 64, 128, 256)
4. Заміни src/images/icon.ico
5. Запусти npm run electron:dev — іконка оновиться в заголовку вікна
6. Для taskbar: npm run dist:win — нова іконка буде в exe і на taskbar
